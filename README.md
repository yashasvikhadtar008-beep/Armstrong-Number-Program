# Armstrong Number Checker

This is a simple Python program that checks whether a given number is an Armstrong Number or not.

## What is an Armstrong Number?

An Armstrong Number is a number that is equal to the sum of its digits raised to the power of the total number of digits.

Example:

153 = 1³ + 5³ + 3³ = 153

Therefore, 153 is an Armstrong Number.

## Features

- Takes input from the user
- Checks if the number is an Armstrong Number
- Uses functions, loops, and conditional statements
- Easy to understand and beginner-friendly
